HUONG DAN CAI DAT MYSHOP GAMING ACCESSORIES POS
================================================

File can chay:

    setup.exe

Ban setup.exe moi nhat sau khi build nam tai:

    installer\output-final\setup.exe

Neu gui bai cho thay, chi can gui file setup.exe nay. Khi thay bam setup.exe,
installer se tu cai cac thanh phan can thiet de chay app.


1. SETUP.EXE SE TU CAI NHUNG GI?
--------------------------------

setup.exe da duoc dong goi de cai:

1. Ung dung MyShop Gaming Accessories POS.
2. .NET 8 Desktop Runtime.
3. Windows App Runtime 1.8 cho WinUI 3.
4. PostgreSQL 18 neu may chua co PostgreSQL dung duoc.
5. Database demo.
6. Du lieu demo tu file dump:

       installer\database\myshop_demo.dump

7. Fallback seed data neu dump khong restore duoc.
8. File cau hinh connection string cho app:

       myshop.database.json

9. Shortcut Desktop:

       MyShop Gaming Accessories POS

10. Shortcut Start Menu:

       MyShop Gaming Accessories POS


2. CAC BUOC CAI DAT CHO THAY
----------------------------

Buoc 1:
    Bam chuot phai vao setup.exe, chon Run as administrator.

Buoc 2:
    Cho installer tu kiem tra runtime, PostgreSQL va database.
    Qua trinh nay co the mat vai phut vi setup.exe co cai kem PostgreSQL.

Buoc 3:
    Sau khi cai xong, mo ung dung bang shortcut:

       MyShop Gaming Accessories POS

Buoc 4:
    Dang nhap bang mot trong cac tai khoan demo:

       admin / MyShop123!
       moderator / MyShop123!
       sale / MyShop123!


3. DATABASE DUOC CAI NHU THE NAO?
---------------------------------

Installer uu tien restore database demo tu dump:

    installer\database\myshop_demo.dump

Neu restore dump thanh cong, database sau cai se giong database demo da export.

Neu dump bi thieu, PostgreSQL tools bi thieu, hoac restore bi loi, installer se
fallback sang seed data bang code trong app. Seed fallback van co categories,
products, customers, orders, promotions, users demo va loyalty data can thiet
cho Dashboard, Reports va Customers.


4. NEU MAY DA CO POSTGRESQL
---------------------------

Neu may da co PostgreSQL va biet mat khau admin postgres, co the set bien moi
truong truoc khi chay setup:

    MYSHOP_POSTGRES_ADMIN_PASSWORD

Neu khong set bien nay, installer se cai PostgreSQL rieng cho MyShop tren port
trong tiep theo, vi du 5433 hoac 5434, de tranh dung nham database co san.

Neu port 5432 bi chiem:

    Khong sao. Installer se tu tim port trong tiep theo cho PostgreSQL MyShop.


5. NOI APP DUOC CAI
-------------------

Mac dinh app duoc cai vao:

    C:\Program Files\MyShop POS

File chay chinh:

    C:\Program Files\MyShop POS\ProjectTest.exe

File cau hinh database:

    C:\Program Files\MyShop POS\myshop.database.json


6. LOG KHI CAI DAT
------------------

Neu cai dat loi, kiem tra log tai:

    C:\ProgramData\MyShop POS\Logs\setup-log.txt
    C:\ProgramData\MyShop POS\Logs\restore-demo-database.log

Inno Setup cung co log rieng trong thu muc Temp cua Windows.


7. CAC LOI THUONG GAP
---------------------

Loi thieu quyen admin:
    Chay lai setup.exe bang Run as administrator.

Loi Windows App Runtime hoac Microsoft.WinUI:
    Chay lai setup.exe bang Run as administrator de installer cai Windows App
    Runtime 1.8. Neu van loi, cai file runtime trong thu muc prerequisites cua
    installer.

Loi PostgreSQL:
    Kiem tra log:

       C:\ProgramData\MyShop POS\Logs\setup-log.txt
       C:\ProgramData\MyShop POS\Logs\restore-demo-database.log

    Neu may da co PostgreSQL va muon dung PostgreSQL do, set bien:

       MYSHOP_POSTGRES_ADMIN_PASSWORD

    roi chay lai setup.exe.

Windows bao app khong ro nguon goc:
    Chon More info, sau do Run anyway neu Windows SmartScreen hien canh bao.


8. NEU CAN TEST INSTALLER TAI MAY DEV
-------------------------------------

Co the chay script test local:

    powershell -ExecutionPolicy Bypass -File .\scripts\test-installer-local.ps1 -SetupPath .\installer\output-final\setup.exe -Silent

Script nay se:

1. Chay setup.exe silent.
2. Kiem tra app exe ton tai.
3. Kiem tra shortcut Desktop.
4. Kiem tra database Products, Customers, Orders neu tim thay psql.
5. Ghi log vao:

       installer-test.log


9. FILE SETUP DE NOP
--------------------

Dung file:

    installer\output-final\setup.exe

Neu muon copy ra ngoai de nop, chi copy file setup.exe nay la du.
