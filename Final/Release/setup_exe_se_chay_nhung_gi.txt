SETUP.EXE SẼ CHẠY NHỮNG GÌ
===========================

Lưu ý: Thư mục Release hiện tại chưa kèm setup.exe. File này dùng để giải thích luồng cài đặt dự kiến khi nhóm tự tạo lại setup.exe.

Khi người dùng bấm setup.exe, installer sẽ thực hiện các bước sau:

1. Kiểm tra môi trường Windows
- Kiểm tra máy có đủ .NET 8 Desktop Runtime để chạy app WinUI/.NET hay chưa.
- Kiểm tra Windows App Runtime đúng phiên bản app đang dùng.
- Nếu thiếu runtime, installer sẽ cài runtime đi kèm hoặc báo rõ người dùng cần cài thêm.

2. Cài hoặc kiểm tra PostgreSQL
- Kiểm tra máy đã có PostgreSQL hay chưa.
- Nếu đã có PostgreSQL, installer dùng PostgreSQL hiện tại.
- Nếu chưa có, installer sẽ cài PostgreSQL theo gói đi kèm hoặc hướng dẫn người dùng cài PostgreSQL.
- Kiểm tra các công cụ psql, pg_dump, pg_restore để backup/restore database.

3. Copy app vào thư mục cài đặt
- Copy ProjectTest.exe.
- Copy ProjectTest.dll, ProjectTest.deps.json, ProjectTest.runtimeconfig.json.
- Copy toàn bộ DLL dependency cần thiết.
- Copy Assets và Assets/GamingProducts để app hiển thị hình sản phẩm.
- Copy file cấu hình và các file runtime cần thiết.

4. Tạo và cấu hình database
- Tạo database MyShop nếu chưa tồn tại.
- Ghi connection string để app đọc được khi mở lên.
- Ưu tiên restore dữ liệu demo từ file PostgreSQL dump nếu installer có kèm installer/database/myshop_demo.dump.
- Nếu không có dump hoặc restore lỗi, app sẽ fallback sang seed demo bằng code.

5. Dữ liệu demo sau khi cài
- Có tài khoản đăng nhập:
  + admin / MyShop123!
  + moderator / MyShop123!
  + sale / MyShop123!
- Có danh mục sản phẩm gaming accessories.
- Có sản phẩm demo kèm hình ảnh.
- Có khách hàng, đơn hàng, khuyến mãi, loyalty và dữ liệu báo cáo demo.

6. Tạo shortcut
- Tạo shortcut ngoài Desktop tên MyShop Gaming Accessories POS.
- Tạo shortcut trong Start Menu nếu installer hỗ trợ.
- Shortcut sẽ mở đúng ProjectTest.exe trong thư mục cài đặt.

7. Ghi log cài đặt
- Ghi log setup để biết runtime/database/app đã được cài như thế nào.
- Ghi log restore database nếu có chạy restore dump.
- Nếu cài lỗi, log sẽ ghi rõ thiếu runtime, thiếu PostgreSQL, sai connection string hoặc restore database lỗi.

8. Sau khi cài xong
- Người dùng có thể mở app bằng shortcut Desktop hoặc Start Menu.
- Nếu database đã cấu hình thành công, app vào thẳng màn hình đăng nhập.
- Nếu database chưa kết nối được, app hiển thị màn hình cấu hình database để nhập lại thông tin PostgreSQL.

Tóm tắt:
- setup.exe dùng để cài đủ runtime, app, database, dữ liệu demo và shortcut.
- Release\App\ProjectTest.exe là bản app đã biên dịch để chạy trực tiếp khi máy đã có đủ runtime và database.
- Nếu sửa code, cần build/publish lại app rồi tạo lại setup.exe để installer chứa bản mới nhất.
